# SMART GUIDE: АДАЛ АЗАМАТ

Цифровой гид по ценностям программы «Адал азамат». Весь сайт на казахском языке, с аудиогидом без акцента.

## Что внутри
- **Карта Казахстана — один большой 3D-мир.** Страна разделена на 6 зон, как экономические регионы, и каждая зона — одна ценность:

| Зона | Города | Ценность |
|---|---|---|
| Север | Астана, Петропавл, Костанай, Павлодар | Тәуелсіздік және отаншылдық |
| Центр | Караганда, Улытау, Жезказган | Бірлік және ынтымақ |
| Восток | Семей, Усть-Каменогорск | Еңбекқорлық және кәсіби біліктілік |
| Юго-восток | Алматы, Талдыкорган | Жасампаздық және жаңашылдық |
| Запад | Атырау, Актобе, Уральск, Актау | Әділдік және жауапкершілік |
| Юг | Туркестан, Шымкент, Кызылорда | Заң және тәртіп |

- **Что есть на карте:** горы (Алатау, Алтай), леса, пустыни, реки (Иртыш, Сырдарья, Или, Урал), озёра (Балхаш, Арал), 23 города и достопримечательности: Байтерек, Хан Шатыр, мавзолей Яссауи, Байконур, нефтекачалки, Кок-Тобе, памятник Абаю.
- **Режимы карты:** «Шолу» (вид сверху), «Ақбарыс» (снежный барс ходит по земле), «Қыран» (орёл летает). Ученики видят друг друга в реальном времени.
- **Порталы и летающие книги** (6 ценностей и 5 праздников) открывают **3D-книгу**:
  - страницы перелистываются, 3D-объекты «вырастают» со страниц;
  - режим **📷 AR**: книга появляется поверх изображения с камеры;
  - внутри книги: чтение с озвучкой, вопросы на читательскую грамотность (можно ответить голосом), «Ойлан» (высказать мнение голосом), музей, лаборатории в юртах, жизненная ситуация, письмо, говорение и результат;
  - из книги можно перейти в предметный мир с квестами.
- **Портал → виртуальный мир.** Через портал ученик попадает в мир ценности: природа, юрты-лаборатории, музей, квест, жизненная ситуация. Раздел **«📖 Кітап»** открывается сверху, когда ученик познакомился с миром.
- **Миры праздников** с квестами: 7 ингредиентов наурыз көже, символы Независимости, шаңырақ единства, порядок по Конституции, звёзды достижений Республики.
- **3D-музей** (раздел «Мұражай» на сайте, павильон в каждом мире, ворота музея на карте): ротонда и 6 залов, 29 экспонатов в 3D-моделях, настоящие фото с указанием авторов (Wikimedia Commons), аудиогид у каждого экспоната.
- **Новые лаборатории:** химия почвы (Еңбекқорлық), природные явления (Жасампаздық), криминалистика с отпечатками пальцев (Заң), физика звука домбры (Бірлік).
- **Праздники:** Наурыз, День Независимости, День единства народа Казахстана (1 мая), День Конституции, День Республики.
- **«Саяхат паспорты» (паспорт путешественника):** штамп за каждый открытый портал, всего 11.

## Кабинет учителя
- Кнопка **👩‍🏫 Мұғалім** вверху справа (есть и на заставке).
- **Готовый аккаунт автора:** логин `mugalim`, пароль `ADAL2026`, код класса **`ADAL10B`**.
- **Любой классный руководитель** может нажать «Жаңа сынып тіркеу» (зарегистрировать новый класс): ввести своё ФИО, школу, класс, логин и пароль. Он сразу получит свой **код класса** и ссылку вида `.../?class=КОД`. Учитель видит только своих учеников.
- **Вкладки кабинета:**
  - 3D-класс: имена учеников онлайн светятся, видно, в какой зоне или книге каждый;
  - список учеников: логины, пароли, время, чтение, баллы; можно заблокировать, удалить, сменить пароль, написать или направить ученика в книгу;
  - ответы (письмо, устные ответы, мнения), статистика, выгрузка в Excel;
  - настройки: открыть или закрыть книги, объявление для всех, смена пароля.

## Ученики
- **Регистрация:** вводят код класса (по ссылке он подставляется сам), имя, фамилию и класс, выбирают персонажа и сразу получают свой логин и пароль.

## Как опубликовать для учеников
1. На github.com создайте репозиторий, например `adal-azamat`.
2. Нажмите **Add file → Upload files** и перетащите всё содержимое папки `smart-guide`.
3. Откройте **Settings → Pages → Branch: main → Save**.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/adal-azamat/?class=ADAL10B`.

## Живой мир
Данные идут через два бесплатных публичных сервера (EMQX и HiveMQ) и шифруются ключом из `js/config.js`. Ничего настраивать не нужно. Хранение на таких серверах не гарантировано, поэтому иногда выгружайте таблицу в Excel.

## Аудиогид
Озвучка сделана нейронным казахским голосом и лежит в `assets/audio`. После изменения текстов перегенерируйте её:
```
pip3 install edge-tts
python3 tools/gen_audio.py
```
